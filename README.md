# Grado-A-Tech

Sitio de ejemplo para ventas de equipos grado "A" (Escritorio, Laptops, PC minis, accesorios y pantallas).

Este repositorio contiene los archivos estáticos para publicar con GitHub Pages desde la rama `main` y la raíz del repositorio.

## Cómo publicar
1. Ve a Settings → Pages en el repositorio.
2. En "Source" selecciona la rama `main` y la carpeta `/ (root)`.
3. Guarda. La URL esperada será: `https://equiposgradoawindows11.github.io/grado-a-tech`.

## Archivos incluidos
- `index.html` — Página principal.
- `styles.css` — Estilos básicos.
- `README.md` — Esta documentación.

Si deseas que añada más secciones (catálogo dinámico, formulario de contacto funcional, carrito, integración con WhatsApp o medios de pago), dime qué prefieres y lo preparo.
